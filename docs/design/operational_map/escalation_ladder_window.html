Escalation ladder window – scale / axis

The need

The current ladder card (460 px, one text column, 7 near-identical rows, Polish text wrapping, ROE lines like “Free to strike: units, air defence, depots”) is hard to scan: nothing tells you where on the scale you are, what is new at each level, or how far the top is. It should be a larger window that draws the seven levels (0–6) as an axis.

Shows (all existing data, read-only): level number + name · where the shared level is now · what may be struck per level (5 target classes: Formations, Air defence, Depots, Airfields, Command posts) · markers where they start: enemy sanctuary soil opens (2), allies join (3), ceiling of ordinary play (5), nuclear attack ends the operation – nobody wins (6) · per side: strength, readiness, collapse threshold ≤ 50 % and a red COLLAPSE tag.

Behaviour (required, same for all variants): X button top-right (28 px, same as the politics screen) · Esc closes · a click outside the window closes · opening it closes every other staff-map window (report, country card, decisions, strike panels, contact notice) and vice versa the other windows already replace it (“one window at a time”) · map dimmed with scrim.screen, no input reaches the map while open · fade 150 ms · opened from the escalation chip (click) – hint “click the chip again / Esc” · no timeout. Meaning is carried by shape and text, not only colour: reached = filled node, current = diamond + “NOW” tag, above current = hollow node, ▲ CAP, ✕ END.

States per frame: left = start of operation (level 1, both sides healthy), right = late game (level 5, Russia in collapse, hover on the level 6 node showing its condition). Nodes colour = existing StaffMapEscalation.level_colour (calm green → ui.alert).
