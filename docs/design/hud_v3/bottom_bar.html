Bottom command bar

One full-width bar docked to the bottom edge of the view. It replaces the floating action bar and takes over everything that now sits along the bottom: the operation label, the terrain / hex card, the ready counter and the end-turn button (battle), and it becomes the single place for the view's buttons. Different content per view: tactical and operational. Keyboard hints stay only as the key caps on the buttons; the separate hint rows are gone, and Save exists only as a button here.

Recommendation and open questions

  • A: everything at the bottom lives in one band, the card keeps all its data, one consistent place to look. B reads cleaner but spends 10 px more and drops card details; C is the lightest but does not satisfy "all elements in the bar".
  • No new tokens: only --panel, --line, --amber, --text, --muted, own / enemy colours. One new value: the greyed End turn fill #3a3f37 already exists in the current button's disabled state (listed here for reference).
  • Staff map: should End turn move from the top turn bar into this bar (right zone, same module as battle)? Proposal keeps it on top to avoid changing the accepted turn bar; the bar shows the ORDERS n / m counter.
  • With 9 buttons the staff-map row is ~800 px wide; below 1280 px the labels shrink to the key cap + icon only (not drawn here).
  • Camera / selection should treat the bar as a 76 px bottom inset so units under it can still be picked from the visible area.
