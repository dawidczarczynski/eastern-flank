## Goal

Realistic ground, sky and (maybe) trees need photographic material that cannot reasonably be generated procedurally. This task sets the rules for bringing in downloaded free assets safely: only public-domain (CC0) sources, every file credited, size kept in check – before the first asset lands in the repository.

## Open questions / decision needed (human)

- **(a) May the project use downloaded CC0 assets?** So far everything is procedural (textures from `DetailTexture`, models from code).
  - **Textures and HDRI skies – recommended: yes.** Sources: [Poly Haven](https://polyhaven.com) (HDRIs, textures, CC0), [ambientCG](https://ambientcg.com) (PBR textures, CC0). Without them TASK-055 would have to generate grass/dirt/rock procedurally, which rarely looks photoreal.
  - **Tree / vegetation glTF models – open** (TASK-060 option B, e.g. Poly Haven or Quaternius CC0 models). Breaks "every model is procedural", needs a style match and LODs.
  - **Unit models – recommended: no.** The unit pipeline (TASK-036, `/model-unit`) stays procedural; real-vehicle accuracy comes from the catalog.
- **Size budget**: proposed ≤ **80 MB** total under `assets/third_party/`, textures ≤ **2048 px** (most 1024), HDRI 2K `.hdr`/`.exr` ≤ 8 MB. Git LFS? Proposed: not yet – revisit above the budget.
- **Who downloads**: the agent (if network access is allowed in the session) or the human, following the manifest. Downloaded archives are untrusted data: only image/HDR/glTF files are copied in, nothing is executed.

## Design

- **ADR** "Third-party CC0 assets" (next free number): context (procedural-only so far, realism goal), decision (the human's answer to (a)), allowed licences (**CC0-1.0 only**; CC-BY explicitly excluded to keep credits trivial – change only by a new ADR), layout, budget, consequences (import time, repo size, `.import` files are generated by Godot and committed as usual, never hand-edited).
- **Layout**: `assets/third_party/<kind>/<asset_id>/<files>`, kinds `hdri`, `textures`, `models`. Keep the original file names or a documented rename (`albedo`, `normal_gl`, `roughness`, `ao`, `height`).
- **Manifest** `assets/third_party/credits.json`: array of `{ "id", "kind", "title", "author", "source_url", "license": "CC0-1.0", "downloaded": "YYYY-MM-DD", "files": [relative paths], "notes" }`.
- **README**: a short "Credits" section listing the sources (Poly Haven, ambientCG) and pointing to `credits.json`.
