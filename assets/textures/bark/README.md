# Bark textures

1K colour maps from https://ambientcg.com, licence CC0 1.0 (public domain, no attribution
required), all tileable. The tree shaders (assets/shaders/foliage_body.gdshaderinc) use them as a
luminance detail map multiplied by the species bark colour (TreeField.bark_texture).

- `bark_oak_ambientcg_Bark012.jpg` – Bark012: oak, alder, shrubs, undergrowth.
- `bark_conifer_ambientcg_Bark014.jpg` – Bark014: pine, spruce.
- `bark_birch_ambientcg_Bark009.jpg` – Bark009: birch (light, peeling).
